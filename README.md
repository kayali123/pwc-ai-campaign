# Human, on Camera — a PwC AI campaign concept

An integrated-marketing **case study**, built as a single scrollytelling page.

**The idea:** turn PwC's real brand line — *"human-led, tech-powered"* — into footage. A behind-the-scenes documentary, in the style of *Clarkson's Farm*, that shows PwC's AI experts getting it wrong before they get it right — to break from the cold, jargon-heavy way every Big Four firm markets AI to a trust-anxious EU market.

- **Author:** Qiaochu Li
- **Context:** University College Dublin, MSc Digital Marketing — capstone group project (team lead & originator). Presented to PwC's team; top grade in the programme.
- **Audience:** EU B2B decision-makers.

> **Honest note.** This is an *academic concept* created at UCD and presented to PwC. It is **not** a PwC-commissioned campaign and is not affiliated with or endorsed by PwC; the PwC name is used to describe the academic brief. Visuals are concept illustrations, not real footage. The only actual outcomes are the top grade and the presentation — every performance figure on the page is a clearly-labelled projection.

## View it
Open `index.html` in any modern browser, or visit the live link once published (see below).

## Publish (GitHub Pages)
1. Create a **public** repo (e.g. `pwc-ai-campaign`).
2. Upload `index.html` (this single file is the whole site — no build step, no dependencies).
3. **Settings → Pages → Source → `main` / root → Save.**
4. Live at `https://<your-username>.github.io/pwc-ai-campaign/` within a minute.

## Tech
Hand-coded HTML/CSS/JS, zero dependencies. Fonts via Google Fonts (Newsreader, Inter, Caveat). Fully responsive, keyboard-accessible, `prefers-reduced-motion`-safe, and degrades gracefully without JavaScript. A print stylesheet turns `Cmd/Ctrl + P → Save as PDF (landscape)` into a clean deck.
