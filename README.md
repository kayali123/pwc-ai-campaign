# Human, on Camera: a PwC AI campaign concept

An integrated-marketing **case study**, built as a single scrollytelling page.

**The idea:** turn PwC's real brand line, *"human-led, tech-powered,"* into footage. A behind-the-scenes documentary, in the style of *Clarkson's Farm*, that shows PwC's AI experts getting it wrong before they get it right. The point is to break from the cold, jargon-heavy way every Big Four firm markets AI to a trust-anxious EU market.

- **Author:** Qiaochu Li
- **Context:** University College Dublin, MSc Digital Marketing. Capstone group project (team lead and originator). Presented to PwC's team; top grade in the programme.
- **Audience:** EU B2B decision-makers.

> **Honest note.** This is an *academic concept* created at UCD and presented to PwC. It is **not** a PwC-commissioned campaign and is not affiliated with or endorsed by PwC; the PwC name is used to describe the academic brief. The hero image is a representative stock photo of a film shoot (via Pexels), not footage of this concept, which was never produced. Every performance figure on the page is a clearly-labelled projection. The only actual outcomes are the top grade and the presentation to PwC.

## View it
Open `index.html` in any modern browser, or visit the live link once published (see below).

## Publish (GitHub Pages)
1. Create a **public** repo (e.g. `pwc-ai-campaign`).
2. Upload `index.html` together with all three images: `hero.jpg`, `og.jpg`, `idea.jpg` (no build step, no dependencies).
3. **Settings → Pages → Source → `main` / root → Save.**
4. Live at `https://<your-username>.github.io/pwc-ai-campaign/` within a minute.

## Tech
Hand-coded HTML/CSS/JS, zero dependencies. Fonts via Google Fonts. Fully responsive, keyboard-accessible, WCAG-AA contrast, `prefers-reduced-motion`-safe, with Open Graph tags for link previews. Degrades gracefully without JavaScript. A print stylesheet turns `Cmd/Ctrl + P → Save as PDF (landscape)` into a clean deck.
